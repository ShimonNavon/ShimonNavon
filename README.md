## What I build

I am an independent full-stack builder and infrastructure operator based in Israel. I design the workflow, build the product, deploy it, and stay responsible for the database, backups, monitoring, and the next release.

- **Custom business systems** — workflows, budgets, permissions, dashboards, and internal tools.
- **MVPs and web products** — a focused first version with a complete user flow.
- **Production infrastructure** — Docker, PostgreSQL, CI/CD, monitoring, backups, and managed hosting.
- **Hebrew-first experiences** — RTL products designed around real Israeli users and businesses.

## How I work

```text
Understand the real workflow
        ↓
Choose one useful end-to-end flow
        ↓
Build interface + API + data together
        ↓
Deploy with backups and monitoring
        ↓
Learn from real use and improve
```

The client owns the code and data. I prefer small, testable releases, clear operational boundaries, and systems another engineer can understand later.
