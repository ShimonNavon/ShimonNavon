<h2>How I think about engineering</h2>

<ul>
  <li><strong>Security first:</strong> build with professional boundaries from the beginning.</li>
  <li><strong>Database first:</strong> understand the data model before rushing into UI.</li>
  <li><strong>Layered delivery:</strong> validate each layer before stacking more complexity on top.</li>
  <li><strong>Provider-neutral AI:</strong> avoid locking architecture to one model vendor.</li>
  <li><strong>Practical debugging:</strong> prefer command-line validation, clear logs, and small controlled changes.</li>
  <li><strong>Maintainable code:</strong> readable structure, helper functions, less repetition, and explicit assumptions.</li>
</ul>
